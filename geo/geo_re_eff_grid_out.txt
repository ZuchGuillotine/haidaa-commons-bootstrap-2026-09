  C_s = 0.25 -> nu_sgs = 16.88 m^2/s, Re_r_eff = 59
  reproducing nu_sgs = 25 m^2/s at Delta = 30 m, |S| = 0.3 requires C_s = 0.30,
  which is above the usual range; with C_s = 0.18 the correct value is 8.7 m^2/s
  and Re_r_eff = 114, not 40. The assessment's Re_r_eff is therefore about
  3x too small at that operating point. Corrected value used hereafter.

=== (B) self-consistent core: |S| ~ u_theta/r_max, r_max = n*Delta ===
Re_r_eff = (n/C_s)^2 / S_w, with S_w = u_theta/u_r = 8.0 (tornado)
Delta cancels exactly: the effective radial Reynolds number of a simulated
core depends on how many cells resolve it, not on the grid spacing itself.

  Reading: a core resolved by only n = 1-2 cells runs at Re_r_eff of order 3-60,
  i.e. inside or near the construction's O(1) regime. A core resolved by n = 8
  cells already runs at Re_r_eff of order 200-400, and by n = 16 at order 1000.
  The 'LES inhabits the construction's regime' bridge is therefore a statement
  about MARGINALLY RESOLVED cores only, and it dissolves once the core is well
  resolved. This is a sharper and more restrictive claim than the seeding
  assessment's 'Re_r_eff ~ 10-100 for tornado LES'.

  Cells per core radius n giving Re_r_eff in [1,10] at S_w = 8:
    C_s = 0.15 -> n in [0.42, 1.34]
    C_s = 0.18 -> n in [0.51, 1.61]
    C_s = 0.20 -> n in [0.57, 1.79]
    C_s = 0.25 -> n in [0.71, 2.24]
  All of these are BELOW one grid cell, so a genuinely Re_r_eff = O(1-10)
  simulated core cannot exist on the grid at all under a Smagorinsky closure.
  The arrest, if it happens, must occur at Re_r_eff of order 10^1 to 10^3.

  Across the published range of horizontal mixing length used in axisymmetric
  maximum-intensity work (order 100 m to 3 km), the effective radial Reynolds

  (each cell is nu_sgs [m^2/s] / Re_r_eff; mixing length l set equal to Delta)
  Note nu_sgs is LINEAR in l here but QUADRATIC in Delta for Smagorinsky, so the
  two closures predict different grid-refinement scalings of Re_r_eff:
    Smagorinsky at fixed |S|:            Re_r_eff ~ Delta^-2
    Smagorinsky with inertial-range |S| ~ eps^(1/3) Delta^(-2/3): Re_r_eff ~ Delta^-4/3
    TKE-1.5 at fixed e:                  Re_r_eff ~ Delta^-1
    self-consistent core (case B):       Re_r_eff independent of Delta
  A resolution ladder that measures which of these four scalings the model
  actually follows is a direct, cheap test of which arrest mechanism operates.
